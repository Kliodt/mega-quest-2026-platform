# UI-пак квеста

Оформление, собранное по дизайну тизера: тёмно-синий фон со свечением из углов, Druk на заголовках, Raleway в тексте, синий `#1f5fff` как единственный акцент. Здесь лежат только куски интерфейса — ни запросов, ни знания о домене.

## Как смотреть

Как и всё окружение — через Docker. Сторибук поднимается вместе с остальными сервисами:

```
docker compose up          # http://localhost:6006
```

После изменения зависимостей пакеты в контейнерах надо обновить, иначе сторибук не найдёт себя:

```
docker compose exec api npm ci && docker compose restart storybook
```

Истории живут рядом с компонентами (`Button.stories.tsx`), правки подхватываются на лету. Фон и шрифты в сторибуке те же, что в приложении.

Статическую сборку (например, чтобы показать дизайнеру) собирает `docker compose exec web npm run build-storybook -w packages/web` — результат в `packages/web/storybook-static/`.

## Что внутри

| Компонент | Где нужен |
| --- | --- |
| `QuestShell` | экран квеста целиком: тёмное поле, фон, колонка содержимого и прилипающая шапка |
| `Modal` | окно поверх экрана на нативном `dialog`: сканер кода, подтверждение подсказки, история штрафов |
| `RoomPlate` | номер аудитории витринным шрифтом: куда идти, где команда сейчас, что уже пройдено |
| `Button` | четыре вида (основная, вторичная, опасная, призрачная), два размера, надпись на время запроса |
| `IconButton` | глаз в пароле, стрелки и крестик в редакторе маршрута |
| `TextField` | поле с подписью, подсказкой, ошибкой, моношрифтом и слотом для кнопки справа |
| `PasswordField` | `TextField` с показом пароля |
| `SelectField` | выбор команды, корпуса, шага |
| `CodeInput` | код на двери: крупный моноширинный ввод на восемь символов |
| `Card` | секция с заголовком и кнопками |
| `Banner` | ошибка, предупреждение, успех, пояснение |
| `Badge` | состояние шага и статус команды |
| `Spinner` | загрузка с подписью |
| `EmptyState` | «Команд пока нет» |
| `Table` | таблицы админки, с прокруткой вбок для маршрутов |
| `Tabs` | разделы страницы команды |
| `PageTitle` | заголовок экрана в стиле афиши |
| `StepCard` | шаг маршрута: и на карте команды, и в админке |
| `TimeValue` | моноширинное время, крупное в шапке |
| `TimeAdjustmentValue` | поправка со знаком: штраф красным, бонус зелёным |
| `Background` | волны по углам и звёзды; рисуется один раз под всем экраном |

## Правила

- Цвета, отступы, скругления, размеры текста и шрифты — только из `styles/_tokens.scss`. Своих значений в компонентах нет.
- Фокус с клавиатуры виден у всего, что нажимается: миксин `focus-ring` из `styles/_mixins.scss`. Движение — через `motion`, оно само выключается при `prefers-reduced-motion`.
- Заглавные буквы оставлены витринному шрифту (`RoomPlate`, заголовки, кнопка сканирования). Кнопки и бейджи набираются обычным текстом: длинные русские надписи капслоком не читаются на бегу.
- Компоненты не ходят в сеть и не знают про DTO: данные приходят пропсами уже посчитанными (время и поправки — строкой, состояние — enum пака).
- Варианты задаются enum'ами (`ButtonVariant`, `BadgeTone`, `StepCardState`, `RoomPlateSize`), а не строками.
- У всего, что кликается без текста, обязательна подпись: `IconButton` требует `label`.
- Кнопки и поля не ниже 48 px: их нажимают пальцем на ходу.

## Где он используется

Все экраны команды (`pages/LoginPage`, `pages/QuestLayout`, `pages/QuestPage`, `pages/QuestionPage`, `pages/MapPage`), страница проверки кодов `pages/PubBindingsPage` и экраны игр (`games/*`). Админка осталась на старом светлом оформлении из `src/styles/global.scss` и пак не использует — это осознанное разделение: у организатора десктоп и таблицы, у команды телефон и темнота коридора.
