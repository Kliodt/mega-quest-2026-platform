# televisions — Телевизоры

**Статус:** тип на умолчаниях core (текстовый вопрос, ответ `{ text }`, подсказки), своей механики пока нет.

Тоже текстовое, 2 подсказки.

На телевизор выводится картинка с камеры, проведённая через TouchDesigner. Там подключён трекинг жестов рук, и жесты переключают фильтр / эффект на камере. Один из эффектов — ASCII-алфавит из цифр нужной аудитории. Сложность в том, чтобы разгадать жест переключения, найти нужный слой и понять, что это и есть ответ. В цифрах запрятаны номер команды | номер аудитории.
