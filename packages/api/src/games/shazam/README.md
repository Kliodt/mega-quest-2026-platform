# shazam — Шазам

**Статус:** тип на умолчаниях core, своей механики нет. Компонент — `web/src/games/shazam/ShazamContent.tsx`.

Шазамить трек, который играет в аудитории. Вопросы стоят в аудиториях Гривы, Чайки и Биржи и
отличаются только аудиторией: текста задания нет, всё происходит в самой аудитории.

Ответ — номер следующей аудитории команды, и ядро подставляет его по маршруту
(`answerIsNextRoom` и `hasDynamicAnswer`). Поэтому команда не вводит ответ руками, а доходит
до аудитории и сканирует код на её двери — общий компонент `web/src/games/roomCodeAnswer/`.
Подсказок нет, штрафа за попытку нет.
