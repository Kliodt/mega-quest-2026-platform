# googleForms — Гугл-формы

**Статус:** реализован. Логики на бэкенде почти нет: вопрос на умолчаниях core, единственный ответ — номер следующей аудитории, и подставляет его ядро по маршруту (`answerIsNextRoom` плюс `hasDynamicAnswer`). Команда сканирует код найденной аудитории. Своё поле у типа одно — `topic`, тема чата: её иконка стоит в шапке формы.

Форму рисует `web/src/games/googleForms/GoogleFormsContent.tsx` — копия настоящей формы регистрации (`tally.so/r/2Ep9vp`) по её же размерам, цветам и шрифту (Inter в `web/public/fonts`). Шапку фронт собирает сам: фирменный фон `web/public/games/form.png`, «Квест» по центру и иконка темы из `web/public/formIcons/<тема>.png` в левом верхнем углу. Заполненное никуда не отправляется: все поля обязательны, а кнопка «Зарегистрировать команду» показывает «Данная форма устарела, попробуйте раньше».

**Задание занимает весь экран** (флаг `fullscreen` в реестре игр фронта): платформы не видно — ни шапки, ни таймера, ни рамки вопроса. Обратно ведёт кнопка «Made with Megabattle» в правом нижнем углу, как «Made with Tally» у настоящих форм; она включается только после первой отправки формы и открывает окно с таймером, подсказками, поддержкой и сканером кода.

Описание формы — это `html` вопроса: у каждой команды своё, и в нём спрятано, какой чат ей нужен. Пока `html` пустой, показывается текст оригинала.

У участников открывается задание на сайте, точно повторяющее гугл-форму реги на квест. Они заполняют форму, и высвечивается текст: «Данная форма устарела, попробуйте раньше». Они переходят на анонс квеста, так как ссылка на форму есть только там, но ссылка другая. В ней находится папка с большим количеством чатов, стилизованных под станции вселенной ИТМО, где в каждой есть ещё топики, и там написано, в каких аудиториях будет проходить станция.

У каждой команды описание формы реги уникальное, и там скрыт, какой чат им нужен, а иконка в шапке — топик.
