# yagodnoe — Ягодное

**Статус:** реализован. Команда — организатор выезда, потерявший список расселения: по анкетам участников она восстанавливает, какой домик заселился первым и кто где спит. Ответ вводится строкой; web-компонент — `web/src/games/yagodnoe/YagodnoeContent.tsx`.

## Как устроено

- **Три варианта вопроса** стоят во всех аудиториях Ягодного, и какой достанется команде, решает ротация ядра. Варианты отличаются только таблицей анкет и ответом, текст у них общий.
- **Свои поля вопроса** (`schema.ts`): `intro` — вводная (`{ html }`), `tableUrl` — ссылка на таблицу с анкетами участников, у каждого варианта своя. Само задание лежит в базовом `html`.
- **Экран команды:** карта Ягодного (`web/public/games/yagodnoe.jpg`), вводная, кнопка «Анкеты участников» (открывает таблицу в новой вкладке), текст задания, поле ответа.
- **Ответ — имена по спальным местам** в порядке №1 №2 №3 №4, например `Аня Ш Гриша К Егор К Варя Е`. Сравнение обычное, с нормализацией core: trim, схлопывание пробелов, нижний регистр, — поэтому регистр и лишние пробелы команде не мешают.
- **Две подсказки:** номер домика и первый жилец.
