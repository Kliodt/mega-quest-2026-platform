# history — История

**Статус:** реализован. Вопрос обычный, свой только `toPublicContent` (`games/history/index.ts`); на фронте компонент `web/src/games/history/HistoryContent.tsx`.

Текстовое задание, 2 подсказки. Номер следующей аудитории в тексте не называется: он спрятан в адресе страницы задания. Компонент подменяет адрес на `/question/<номер>`, найти его там и есть загадка. Номер берётся из самого вопроса — это его ответ, первый элемент `acceptedAnswers`, поэтому в данных он лежит в одном месте. Ответ, как и у энциклопедии, — номер следующей аудитории, поэтому вводится он сканированием кода на её двери (общий компонент `web/src/games/roomCodeAnswer/`). В данных ответ должен указывать на аудиторию существующей игры.

Первое задание корпусов Грива / Биржа / Чайка начинается с исторической справки. Следующая аудитория спрятана в URL страницы, например `https://sosupenis.com/1217`.
