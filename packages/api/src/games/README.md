# Типы игр

Каждая папка — один тип игры (механика), экспортирующий `GameTypeDefinition` из `types.ts`: какие поля есть у вопроса сверх базовых, что из него видит команда, как проверяется ответ и что показывать организатору. Обязателен только `gameType`: умолчания (текстовое задание, ответ строкой) живут в core, в `utils/question/`. Вопросы всех типов лежат в одной коллекции, читает и пишет их тоже core; роуты команды общие. Реализованный тип регистрируется в `registry.ts`; как добавить новый — в корневом README.

| Папка | Название | Статус |
|---|---|---|
| `shazam` | Шазам | умолчания core |
| `yagodnoe` | Ягодное | умолчания core |
| `encyclopedia` | Энциклопедия | умолчания core |
| `socialNetworks` | Соцсети | умолчания core |
| `history` | История | свой `toPublicContent` |
| `televisions` | Телевизоры | умолчания core |
| `light` | Свет | умолчания core |
| `googleForms` | Гугл-формы | умолчания core |
| `minesweeper` | Сапёр | поле генерируется при загрузке и лежит в `data` вопроса |
| `soundButtons` | Sound Buttons | свои поля `buttons` и `sequence`, ответ собирается при загрузке |
| `blitz` | Блиц (МегаКвиз) | своё поле `quiz` |
| `stickers` | Стикеры | умолчания core |

Восемь типов (`shazam`, `encyclopedia`, `televisions`, `light`, `googleForms`, `socialNetworks`, `stickers`, `yagodnoe`) пока отличаются только именем и данными: каждый — одна строка в своём `index.ts`. Своя механика добавляется переопределениями (`extraFields` — свои поля вопроса, `toPublicContent` — что видит команда, `checkAnswer` — проверка ответа, `toQuestionData` — что дописать вопросу перед записью в базу, `toAdminContent` — что видит организатор).
