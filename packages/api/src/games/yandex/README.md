# yandex — Яндекс

**Статус:** реализован. Стоит в аудитории 2101 на Кронверкском, вариант у каждой команды свой. Web-компонент — `web/src/games/yandex/YandexContent.tsx`.

## Как устроено

- **Ролик на команду.** У вопроса своё поле `videoUrl` (`schema.ts`): ролик с заголовком «Яндекс в ИТМО: что студенты думают об этой точке на карте?». Заголовок один на всех и живёт в компоненте, ролики разные — в каждом своя геометка в метаданных файла.
- **Вариант привязан к команде** через `teamSlugs`: 72 варианта в одной аудитории, у каждого ровно одна команда. Что вариант есть у каждой команды, проверяет валидатор маршрута.
- **Файлы роликов** лежат статикой в `packages/web/public/yandex_files/` под случайными именами (`<16 hex>.mp4`), чтобы по имени нельзя было найти чужой или свой заранее. В git их нет — 700 МБ, на чистой копии кладутся руками. Соответствие «команда → файл → ответ» лежит рядом с данными: `setup/questions/yandex-videos.csv` (тоже вне git).
- **Ответ — слово**, расшифрованное по Виженеру из геометки: команда переводит координаты в буквы по таблице из текста задания. Сравнение обычное, с нормализацией core, поэтому регистр не важен.
- **Подсказок нет.**
