# stickers — Стикеры

**Статус:** реализован. Вопрос на умолчаниях core: ответ — строка, которую команда собирает из выданных за квест стикеров, и вводит её руками (`web/src/games/stickers/StickersContent.tsx`). Аудиторией ответ не является: дальше команда идёт по своему маршруту. Вопрос один на всех и стоит во многих аудиториях Ломоносова и Кронверкского.

В течение игры капитану команды приходят стикеры с нами как поддержка после выполнения сложного задания. Последнее задание будет отсылать к истории их прохождения. И если они сопоставят человека на стикере с его реальным тг-аккаунтом, то, прочитав описания и составив порядок, получат номер аудитории.
