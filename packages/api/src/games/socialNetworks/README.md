# socialNetworks — Соцсети

**Статус:** реализован. Вопрос на умолчаниях core: в `html` ссылка на ролик (в тестовых данных пока заглушка «тут будет ссылка»). Web-компонент — `web/src/games/socialNetworks/SocialNetworksContent.tsx`, поля ответа у него нет.

Ответ задан заранее и одинаков для всех: строка `SocialNetworksAnswer.CONFIRMED` (`«1»` в `shared/src/games/socialNetworks.ts`), она же лежит в `acceptedAnswers` вопроса. Аудиторией ответ не является: `answerIsNextRoom` и `hasDynamicAnswer` сняты, поэтому маршрут после этого вопроса ничем не связан — команда идёт дальше обычным переходом и сканирует код следующей аудитории.

Засчитывает задание **переход по ссылке из ролика** на `/pub/confirm_video` (`web/src/pages/PubConfirmVideoPage.tsx`):

- команда открыла ссылку на своём устройстве — страница сама отправляет ответ и говорит, что он принят и можно возвращаться к прохождению;
- открыли без входа — страница просит открыть ссылку там, где команда вошла в квест;
- открытого задания нет или открыто другое — ответ не отправляется. Иначе переход по ссылке не вовремя стоил бы команде неверной попытки со штрафом.

Ссылку команда обычно открывает в другой вкладке, поэтому у вопроса поднят флаг `waitsForExternalAnswer` (решение 2026-09-26): core держит долгий запрос состояния, и экран задания уходит на следующий шаг сам, как только ответ засчитан (`api/useQuestionStateWatch.ts`).

Стартовый QR ведёт на рилс / ВК-клип / тикток, в котором обзор на корпус, а в конце показывается ссылка на `/pub/confirm_video`.

У Кронвы видос в арке, надо прийти в арку. На Ломо в видосе мелькает QR.
