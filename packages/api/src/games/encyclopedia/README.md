# encyclopedia — Энциклопедия

**Статус:** тип на умолчаниях core, на фронте свой компонент `web/src/games/encyclopedia/EncyclopediaContent.tsx`.

Текстовое задание, 2 подсказки. Ответ — номер аудитории, поэтому команда не вводит его руками: она доходит до аудитории и сканирует код на двери. Компонент узнаёт номер по коду (`POST /quest/room-number`), отправляет его ответом и при верном ответе тем же кодом открывает следующий вопрос. Значит, ответ каждого варианта должен быть аудиторией существующей игры.

Команде даётся текст, где фигурируют 4 мегаорганизатора. В их персоналиях есть простые загадки, ответом на которые являются слова, которые они должны найти в одном из 9 томов Большой советской энциклопедии. Тома названы числами 1–9 и по алфавиту, например, первый том — А–Ак. Таким образом, зная ответы на 4 загадки, участники выбирают 4 тома, которые формируют номер аудитории. Так как тома 0 не существует, аудитории с нулём в номере не подходят.
